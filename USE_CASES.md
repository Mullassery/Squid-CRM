# Squid-CRM Use Cases

Squid-CRM is a self-hosted CRM for teams that want their data in PostgreSQL and a
typed web client they can extend.

## Common scenarios

- **Self-hosted sales CRM** — manage people, companies, opportunities, tasks and
  notes without a managed SaaS dependency.
- **Internal system of record** — use the REST and GraphQL APIs to sync records
  with warehouses, support tools and automation.
- **Custom object workflows** — create objects and fields at runtime and store
  records in workspace-scoped tables.
- **Private deployments** — run the API and web client on your own network with
  PostgreSQL as the only required service.
- **Development and testing** — exercise auth, tenancy, permissions and metadata
  behaviour against a real PostgreSQL instance.

See [`README.md`](./README.md) and [`docs/api.md`](./docs/api.md) for setup and
API details.
